## Measured dependency fix

The visible РУС language control uses Manrope Cyrillic on every locale.
Its font was discovered after the main stylesheet. Add that existing font to
the initial font preloads so it can load with the other visible typography.

A controlled local comparison using gzip delivery, Lighthouse 13.6 mobile
simulation and CPU slowdown 1.2 measured:

| Variant | FCP | LCP | Performance |
|---|---:|---:|---:|
| Before | 1.070s | 2.108s | 99 |
| Earlier Cyrillic request | 1.069s | 1.877s | 99 |
| Built implementation | 1.069s | 1.877s | 99 |

The font request moved from 42ms (after the stylesheet completed at 20ms)
to 11ms (alongside the stylesheet). In the supplied remote report that font
was the end of the 828ms critical dependency chain.

Image synchronous decoding and removing the mobile hero shadow showed no
meaningful improvement in the same experiment and were not included.

Remote cold runs before the fix varied from performance 89 / LCP 3.7s to
performance 100 / LCP 1.4s. The local paired result therefore establishes a
smaller loading improvement, not a guaranteed new public PageSpeed score.
A fresh public PageSpeed result and real-user field data can differ.
